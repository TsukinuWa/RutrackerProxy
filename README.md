## ⚙️ What it does

Rutracker Proxy is a focused Firefox add-on for reaching RuTracker through a proxy without a manual setup routine. It encrypts the connection with HTTPS, masks the server side of the request and monitors availability so blocks can be noticed early.

From the browser you can open the site, use the forum and browse the torrent catalog — the extension stays free and keeps configuration to a minimum.
